# Table escape probe

Control line, outside any table: bare @CTLBARE, backticked `@CTLTICK`, escaped \@CTLESC,
doubled @@CTLDBL, entity &#64;CTLENT.

| Variant    | Value        |
|------------|--------------|
| bare       | @TBLBARE     |
| backticked | `@TBLTICK`   |
| escaped    | \@TBLESC     |
| doubled    | @@TBLDBL     |
| entity     | &#64;TBLENT  |
